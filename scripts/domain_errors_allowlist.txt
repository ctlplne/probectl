# Domain-error vocabulary allowlist (Foundation-Loop S-ef8e66dc).
#
# Format: <file>:<Receiver>.<Method> — <reason>
#
# An entry needs a written reason; the gate rejects one without it, because an
# exemption nobody had to justify is a denylist entry wearing a comment. A stale
# entry — one whose violation is gone — also fails the gate, so an exemption
# cannot outlive the thing it excused.
#
# The bar for an entry: the method is NOT reachable from an HTTP handler, so
# there is no transport that has to decide a status code. Everything else gets
# an apierror.

internal/store/store.go:DB.WithReadReplica — process bootstrap, not a request path: called once from main() before any listener is bound. A failure here aborts startup with the wrapped cause in the operator's log; there is no HTTP status to choose.
internal/store/enrollment.go:BMPRevocations.List — standalone-listener path (cmd/probectl-bmp-listener), reached from no HTTP handler. The listener replaces its in-memory revocation list only when this succeeds and logs the wrapped cause otherwise; a Kind would have no transport to travel over.
internal/store/alertactive.go:AlertActiveState.Replace — alert-evaluator background path: the leased singleton writes the active-alert snapshot and its heartbeat on a timer, reached from no handler. A failure is logged with the wrapped cause and the next evaluation retries; there is no request whose status code a Kind could set.
internal/store/compliancealerted.go:ComplianceAlerted.Claim — bus-consumer path: the segmentation consumer races replicas for the once-only export claim while handling a bus record. The caller deliberately fails open on error (a violation is never dropped because the database blinked) and logs the wrapped cause; no HTTP response is being shaped.
internal/store/costbudgetalerted.go:CostBudgetAlerted.Claim — bus-consumer path: the cost consumer's once-only budget-breach claim, taken while handling a flow record. Same fail-open-and-log contract as the segmentation gate; no transport is choosing a status code.
